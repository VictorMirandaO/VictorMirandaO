# `08 // SNAKE PROTOCOL`

<div align="center">

<img src="https://raw.githubusercontent.com/VictorMirandaO/VictorMirandaO/output/github-contribution-grid-snake.svg" width="100%" alt="GitHub Contribution Snake">

</div>

> The Snake requires the GitHub Action below to generate the SVG automatically.

### `.github/workflows/snake.yml`

```yaml
name: Generate Contribution Snake

on:
  schedule:
    - cron: "0 0 * * *"
  workflow_dispatch:

jobs:
  generate:
    runs-on: ubuntu-latest

    steps:
      - name: Generate Snake
        uses: Platane/snk@v3
        with:
          github_user_name: ${{ github.repository_owner }}
          outputs: |
            output/github-contribution-grid-snake.svg

      - name: Push generated SVG
        uses: EndBug/add-and-commit@v9
        with:
          message: "chore: update contribution snake"
          add: "output/github-contribution-grid-snake.svg"
